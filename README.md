# AI Movie Recommendation System

A beginner-friendly AI-based Movie Recommendation System developed using Python, Pandas, and Streamlit.

This application recommends movies based on genre similarity. When a user enters a movie name, the system suggests other movies from the same genre.

---

# Features

- Movie recommendation based on genre
- User-friendly web interface
- Built using Streamlit
- Uses CSV dataset
- Beginner-friendly AI project


#  AI Concept Used

## Content-Based Recommendation System

The project recommends movies by comparing genres and suggesting similar movies.
